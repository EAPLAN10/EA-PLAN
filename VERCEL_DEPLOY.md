# EA PLAN — Vercel Final

This package is a static client-side web app.

## Vercel
- Framework preset: Other / None
- Build command: leave empty
- Output directory: leave empty
- Root directory: the directory containing `index.html`
- No `vercel.json` is required.

## Repository structure
`index.html` must be at the repository root, alongside `public/` and `src/`.

Assets in `public/assets/` are referenced as `/assets/...`.
