# EA PLAN Final Scope

The final UI is organized around these spaces:

- Beranda
- Planning
- Goals
- Journal
- Ideas
- Projects
- Journey
- Statistik
- Profil
- Jelajahi
- Koleksi
- Tentang EA PLAN
- Panduan

The profile menu exposes Statistik, Jelajahi, Koleksi, Tentang EA PLAN, and Panduan. The mobile bottom navigation keeps the five highest-frequency spaces: Beranda, Planning, Goals, Journal, and Profil.

## Home rules

The home page does not duplicate the Statistik dashboard. Progress keseluruhan, Target Aktif, Projects, Journal, and Ringkasan belong to Statistik. Home keeps lightweight activity summaries plus Menarik Dilihat and Komentar Mereka.
